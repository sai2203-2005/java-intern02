# Student Grade Calculator

A simple and robust Java console application that calculates total marks, percentage, and assigns grades based on input marks for multiple subjects.

## Features
- Input validation for subject count and individual marks (0 to 100).
- Calculates total marks and overall percentage.
- Determines grade based on percentage:
  - **A+**: 90% and above
  - **A**: 80% - 89%
  - **B**: 70% - 79%
  - **C**: 60% - 69%
  - **D**: 50% - 59%
  - **E**: 40% - 49%
  - **F**: Below 40%

## How to Run

1. **Compile**:
   ```bash
   javac StudentGradeCalculator.java
   ```

2. **Execute**:
   ```bash
   java StudentGradeCalculator
   ```
